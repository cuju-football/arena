# Cuju Arena security policy

Send a private vulnerability report through the [Security tab](https://github.com/cuju-football/arena/security).
Include your arena and engine versions, the operating system, and a minimal example.
Keep private submissions and recordings out of reports unless you can share them.

Team submissions, formats and plugins can run Python code. Use trusted folders and
archives. The [submission format guide](docs/formats.md) describes the arena checks
and the worker controls that apply to each format. The [plugin guide](docs/plugins.md)
describes the code that an installed or home-folder plugin runs.
